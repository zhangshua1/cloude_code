**打印注意事项**:
- 大腿和小腿沿 Z 轴竖立打印（层间平行于受力方向，强度最大化）
- 机身壳体后盖向下打印，减少悬空面
- TPU 轮毂 D-cut 轴孔方向对齐可减少支撑需求

### 1.4 重心分析

```
坐标系: 轮轴中心为原点，Z轴向上为正

轮轴中心:     0mm      ← 参考原点
小腿+轮电机:  +18mm    ← N20 电机 + TPU 轮毂 (~55g)
膝关节:      +45mm    ← MG90S 舵机 (~14g)
大腿:        +65mm
髋关节:      +85mm    ← MG90S 舵机 (~14g)
电池:        +95mm    ← 最大质量集中点 (~80g)
PCB+主控:   +105mm    ← ESP32-S3 + 模块 (~40g)
IMU:        +115mm    ← MPU6050
头部舵机:   +130mm
头部+显示屏: +145mm

估算重心高度: ~+95mm (高于轮轴形成倒立摆)
```

- 重心高于轮轴是实现自平衡的必要条件
- ~95mm 重心高度适中：既提供足够控制力矩，又不会过高导致控制难度急剧增大
- X/Y 轴重心接近中心（电池居中，左右对称布局）

## 四、平衡控制算法

### 4.1 级联 PID 架构 (200Hz)

```
Setpoint(0°) ──→[+]──→ PID_Angle ──→ [+] ──→ PID_Rate ──→ Motor PWM
                  ↑                    ↑                    │
             angle_fused         gyro_rate_y          ┌─────▼──────┐
             (互补滤波)           (陀螺仪 Y 轴)        │ L_PWM/R_PWM│
                  │                    │               │ TB6612FNG  │
             ┌────┴────┐         ┌────┴────┐         └────────────┘
             │ MPU6050 │         │ MPU6050 │
             │ 加速度计 │          │  陀螺仪  │
             └─────────┘         └─────────┘
```

**外环 (角度控制)**: 输入=目标俯仰角(通常 0°)，输出=期望角速度。P 项快速响应、I 项消除静差、D 项抑制过冲。

**内环 (角速度控制)**: 输入=外环输出(期望角速度)，输出=电机 PWM 占空比。直接抑制高频振荡，响应更快。

### 4.2 初始 PID 参数 (需实机整定)

```cpp
// 外环 - 角度控制
angle_pid = {
    .kp = 35.0, .ki = 4.0, .kd = 0.3,
    .integral_limit = 500,  // 积分抗饱和
    .output_limit = 300,    // 输出限幅
    .lowpass_alpha = 0.9    // 低通滤波
};

// 内环 - 角速度控制 (高频，更快响应)
rate_pid = {
    .kp = 0.8, .ki = 0.15, .kd = 0.01,
    .integral_limit = 100,
    .output_limit = 255,    // PWM 满幅
    .lowpass_alpha = 0.7
};
```

### 4.3 调参策略 (Ziegler-Nichols + 手动)

```
Step 1: Ki=Kd=0, 仅调 angle.Kp (10→逐步↑至短暂站立但不稳)
Step 2: 引入 rate.Kp 抑制振荡
Step 3: angle.Ki 微小值起步，消除稳态误差
Step 4: angle.Kd 抑制过冲
Step 5: rate.Ki 改善速度跟踪
Step 6: 微调低通滤波系数 (处理机械振动耦合)
```

### 4.4 互补滤波 (IMU 姿态融合)

```
angle = 0.96 × (angle_prev + gyro × dt) + 0.04 × accel_angle

α=0.96: 陀螺仪权重高 (短期精度好)
1-α=0.04: 加速度计修正 (长期绝对参考)
```

### 4.5 安全机制

- **跌倒检测**: |俯仰角| > 45° 持续 300ms → FALL 模式 → 电机急停
- **低压保护**: 电池 < 6.2V → 退出平衡 → LED 闪烁告警
- **IMU 超时**: 100ms 无新数据 → ERROR 模式 → 电机释放
- **看门狗**: 3s 无喂狗 → ESP32 自动复位

## 五、AI 对话模块

### 5.1 硬件连接

```
INMP441 麦克风模块
  VDD  → 3.3V
  GND  → GND
  SD   → GPIO18 (I2S0 DIN)
  SCK  → GPIO15 (I2S0 BCK, 共享)
  WS   → GPIO16 (I2S0 WS, 共享)
  L/R  → GND (配置为左声道)
```

INMP441 与 MAX98357 共享 I2S0 总线的 BCLK/WS，ESP32-S3 I2S 全双工模式下输入和输出同时工作。

### 5.2 对话 Pipeline

```
按键触发 (BOOT) / WebUI 文字输入
         │
         ▼
    ┌─────────┐
    │ LISTENING │  INMP441 PCM 16kHz 16bit 录音
    │ (录音中)  │  VAD 自动断句 (能量阈值+静音超时)
    └────┬────┘
         │ AudioBuffer (int16_t[], 最多5秒)
         ▼
    ┌──────────┐
    │ THINKING  │  HTTP POST → STT API
    │ (ASR)     │  百度语音识别 / OpenAI Whisper
    └────┬─────┘
         │ 返回文字
         ▼
    ┌──────────┐
    │ THINKING  │  HTTP POST → LLM API
    │ (LLM)     │  DeepSeek / OpenAI / Claude
    └────┬─────┘
         │ 返回文字回复
         ▼
    ┌─────────┐
    │ SPEAKING │  HTTP POST → TTS API
    │ (TTS)    │  微软 Edge TTS (免费) / OpenAI TTS
    └────┬────┘
         │ PCM 音频
         ▼
    ┌──────────┐
    │ 播放+显示 │  MAX98357 喇叭播放
    │           │  TFT 显示文字回复 + 表情联动
    │           │  舵机做对应动作 (开心=挥手等)
    └──────────┘
```

## 八、装配与调试流程

### 阶段一：打印与后处理 (2~3 天)

| 步骤 | 内容 | 耗时 |
|------|------|------|
| Day 1 | PETG 结构件打印 (机身左右壳 + 腿部 + 底盖) | ~8h |
| Day 2 | PLA+ 外观件打印 (头壳前后盖 + 舵机支架) | ~4h |
| Day 3 | TPU 轮毂打印 + 全部后处理 (去支撑、打磨配合面、验证孔位) | ~2h |

### 阶段二：电子预测试 (1 天)

1. I2C Scanner → 确认 0x68 (MPU6050) + 0x40 (PCA9685)
2. ST7789 显示测试 → "Hello PenguinBot" 全屏填充
3. TB6612 + N20 空载测试 → 正反转 + PWM 调速
4. PCA9685 + MG90S 扫描测试 → 0°~180° 全范围
5. MAX98357 音频测试 → 1kHz 正弦波
6. INMP441 录音测试 → I2S read → 串口打印 RMS
7. 电源系统验证 → MP1584 校准 5V ±0.1V，满载纹波 <100mV
8. 电池充放电循环测试 → 记录容量和放电曲线

### 阶段三：分层组装 (1 天)

1. 腿部预装：N20 装入小腿壳 → AS5600 贴尾部 → 磁铁粘轴端→ 套 TPU 轮毂 → 膝舵机装入大腿 → 连接大小腿
2. 机身预装 (左)：PCA9685 + TP5100 + 电池仓 + JST 座
3. 机身预装 (右)：ESP32 + TB6612 + MP1584 + AMS1117 + INMP441
4. 合拢：连接 JST 接插件 → 腿部连髋关节 → 头部连机身 → 底盖螺丝

### 阶段四：固件烧录 (0.5 天)

```bash
cd firmware
pio run -t upload        # 烧录固件
pio run -t uploadfs      # 上传 WebUI
pio device monitor       # 串口日志
```

确认：
- [ ] 串口无错误输出
- [ ] TFT 显示 "PenguinBot v2.0" 启动画面
- [ ] WiFi AP "PenguinBot-XXXX" 可发现
- [ ] 浏览器打开 `http://192.168.4.1` 可访问 WebUI
- [ ] WebSocket 连接 (状态点变绿)

### 阶段五：平衡调试 (核心，1~2 天)

1. **安全准备**: 安装防倾倒支架 (仅允许 Pitch 单轴旋转)，准备紧急停止按钮
2. **IMU 校准**: 静止 2s → 采 500 样本求 gyro bias，确认静止噪声 <0.05°/s
3. **PID 逐环调试**:
   - rate 环方向验证 (正向转动机器人→车轮应反向加速)
   - angle.Kp 粗调 (10→25→35→45，至能短暂站立)
   - rate.Kp 精调 (抑制 angle 环引发的振荡)
   - angle.Ki 消静差 (从 0.5 开始逐步增加)
   - angle.Kd 抑过冲 (从 0.1 开始逐步增加)
4. **自由平衡**: 移除支架，平整桌面测试扰动恢复 (超调量/稳定时间/稳态误差)
5. **遥控测试**: WebUI DPAD 控制前后左右移动

### 阶段六：AI 对话集成 (0.5 天)

1. 配置 API Key (WebUI → AI 对话 → API 设置)
2. 语音测试: 按 BOOT 键 → 说话 → 等待回复
3. 文字测试: WebUI 聊天框输入 → 回车 → 查看回复 + TTS 播放
4. 表情联动验证: "讲个笑话" → HAPPY，"说对不起" → SAD

### 阶段七：表情与动画集成 (0.5 天)

1. 表情精灵部署 → 逐表情验证
2. WebUI 舵机面板编排关键姿势
3. 动作序列录制 + 表情联动
4. 确认舵机动作不干扰平衡

## 十、故障排查

| 现象 | 可能原因 | 排查步骤 |
|------|----------|----------|
| MPU6050 初始化失败 | I2C 接线错误或地址冲突 | I2C Scanner 确认 0x68 存在；检查 SDA/SCL 上拉 2.2kΩ |
| 零点漂移过大 (>0.5°/min) | 温度变化 / 器件品质 | 重新上电校准；换 ICM-20948 |
| 机器人站不起来 | PID 参数不适配 | 检查重心是否偏移；rate 环方向是否正确；angle.Kp 从小到大逐步增加 |
| 抖动剧烈 | Kp 过大或机械松动 | 减小 angle.Kp；检查轮毂与轴是否松动 |
| WiFi 连接不上 | ESP32-S3 射频干扰 | 远离金属外壳；确认天线区域无遮挡 |
| WebSocket 断开频繁 | WiFi 信号弱 | 缩短距离；检查电源纹波 |
| 舵机异响/抖舵 | 供电不足或 PWM 频率不对 | 测量 5V Rail 电压；确认 PCA9685 50Hz |
| 电机不动 | TB6612 STBY 未拉高 | 检查 GPIO44 电平；量 VM 电压 |
| AS5600 读数不动 | 磁铁距离太远/极性反 | 间隙 0.5~2mm；确认径向磁铁安装方向 |
| INMP441 录音无声 | L/R 引脚未接地 | 检查 INMP441 L/R 接地；确认 I2S DIN 通道 |
| AI 无回复 | API Key 错误或网络不通 | 检查 DeepSeek/OpenAI API Key；确认 ESP32 能访问外网 (需 STA 模式) |
| TFT 花屏 | SPI 速率过高或接线不良 | 降低 SPI 频率至 20MHz；重插排线 |
| 续航严重不足 | 电池老化或舵机堵转 | 检查电池内阻；确认舵机无卡死 |
