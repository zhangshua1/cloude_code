## 二、打印参数

```
打印机: FDM (推荐 Bambu Lab P1S/X1C)
层高:   0.12mm (外观件) / 0.16mm (结构件)
壁厚:   3 层 (≥1.2mm)
热床:   PLA+ 55°C / PETG 80°C / TPU 45°C
喷嘴:   PLA+ 210°C / PETG 245°C / TPU 230°C
TPU:    速度降至 30mm/s
```

**关键注意事项**:
- 腿部零件沿 Z 轴竖立打印（层间方向平行于受力方向）
- 所有舵机安装孔预留 0.15mm 间隙补偿
- TPU 轮毂打印前彻底干燥（55°C × 6h）
- 机身壳体后盖向下打印，减少悬空面

## 三、装配步骤

### L0: 腿部预装

1. N20 电机装入小腿电机座，M2 螺丝固定
2. AS5600 编码器 PCB 插入小腿尾部卡槽
3. Φ6×2mm 径向磁铁用 401 胶粘在电机轴尾端（注意极性，AS5600 检测距离 0.5-2mm）
4. TPU 轮毂套上电机轴，D-cut 对齐，轻压至底部
5. 验证：用手转动轮毂应顺畅，编码器能读取角度变化

### L1: 膝关节

1. MG90S 舵机装入大腿底部舵机仓
2. 舵机归中（90°），安装舵盘
3. 小腿顶部与舵盘对齐，M2 自攻螺丝锁紧
4. 验证：舵机转动时小腿应平滑跟随

### L2-L3: 机身

1. 机身左壳：安装 PCA9685 模块（M2 铜柱）、TP5100 充电模块、电池仓
2. 机身右壳：安装 ESP32-S3、TB6612 模块、MP1584、AMS1117
3. MPU6050 用双面胶固定在机身中心位置（靠近电池上方）
4. 母头 USB-C 嵌入底盖充电口

### L4: 机身合拢

1. 连接左右壳之间的 JST 接插件（电机线、舵机线、I2C 总线）
2. M2×15 铜柱对锁左右壳
3. 底盖螺丝固定

### L5: 髋关节

1. 髋支架用 M2 螺丝固定在机身底部两侧
2. MG90S 髋舵机装入支架，归中 90°
3. 大腿顶部与髋舵机舵盘对齐锁紧

### L6: 头部

1. 头壳后盖安装 MG90S 摇头舵机
2. TFT 显示屏嵌入头壳前盖显示窗口，PCB 用螺丝固定
3. 舵机支架连接前后盖，卡扣合拢
4. TFT 排线从头部经舵机支架中心孔穿过

### L7: 总装

1. 头部组件与机身顶部对插，M2 螺丝固定
2. TFT 排线和舵机线从机身顶部走线孔穿入
3. 连接所有接插件：电机 ×2、舵机 ×5、TFT SPI、I2C、电池、喇叭
4. 电池放入电池仓，接上电源线
5. 底盖合上，不拧紧（便于调试）

## 四、接线检查清单

- [ ] I2C 总线上拉电阻确认（SCL/SDA 各 2.2kΩ 至 3.3V）
- [ ] MPU6050 I2C 地址 0x68 不冲突 PCA9685 地址 0x40
- [ ] 电机线双绞（减少 EMI）
- [ ] 舵机 5V 独立供电（从 MP1584 5V Rail 直出，不经 3.3V LDO）
- [ ] 电池正负极无短路（万用表蜂鸣档验证）
- [ ] 各模块 GND 星形连接至电池负极

## 五、首次上电

1. **不要安装轮子**，先用面包板电源供 5V 到 ESP32 USB
2. 打开串口监视器（115200bps），观察启动日志
3. 确认 I2C 扫描：0x68（MPU6050）、0x40（PCA9685）
4. TFT 应显示 "PenguinBot v1.0.0" 启动画面
5. 手机搜索 WiFi "PenguinBot-XXXX"，连接密码 `penguin123`
6. 浏览器打开 `http://192.168.4.1`，确认 WebUI 加载
7. 逐通道测试舵机：WebUI 舵机面板拖动每个滑块
8. 测试电机：WebUI 移动面板点按方向键（轮子空载）
9. 全部正常后，关机，安装轮子，准备平衡调试
